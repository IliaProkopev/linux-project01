# Как приготовить жаренную картошку
Жаренная картошка - это одно из самых вкусных блюд.
Главный секрет хрустящей корочки - нарезать картошку, высушить его бумажным полотенцем и выкладывать только на хорошо разогретую сковороду с маслом.
```python
time_minutes = 20
is_ready = True

if is_ready:
    print(f"Жарим {time_minutes} минут: картошка готова!")
